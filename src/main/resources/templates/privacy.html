개인정보처리방침

시행일: 2026년 9월 25일

달빛타로(이하 '서비스')는 회원가입 없이 이용하는 무료 타로 해석 서비스입니다. 서비스 운영에 필요한 최소한의 정보만 수집하며, 그 내용을 아래와 같이 안내합니다.

1. 수집하는 항목

구분항목수집 방식
선택 입력생년월일, 성별이용자가 직접 입력 (입력하지 않아도 이용 가능)
이용 정보선택한 관심 분야, 뽑은 카드, 생성된 해석 문장서비스 이용 시 자동 생성
접속 기록접속 IP 주소, 요청 시각, 응답 시간서버 로그로 자동 기록

이름, 연락처, 이메일 주소는 수집하지 않습니다. 회원가입 절차가 없으며 로그인 정보를 보관하지 않습니다.

2. 수집 및 이용 목적

  • 생년월일·성별: 해석 문장을 만들 때 참고 정보로 사용합니다. 실제 사주(만세력)를 계산하지 않습니다.
  • 관심 분야·뽑은 카드·해석 문장: 결과 화면을 보여주고, 공유 링크로 다시 열어볼 수 있게 저장합니다.
  • 접속 IP 주소: 짧은 시간에 반복되는 과도한 요청을 제한하는 데 사용합니다. 이 목적의 IP 기록은 1분 이내에 서버 메모리에서 사라집니다.
  • 요청 시각·응답 시간: 장애 확인과 비용 점검에 사용합니다. 이 기록에는 생년월일·성별이 포함되지 않습니다.

3. 제3자 전송 (해외 이전)

해석 문장을 만들기 위해 외부 인공지능 사업자에게 아래 정보를 전송합니다. 이 전송에 동의하지 않으시려면 서비스를 이용하지 않거나, 생년월일·성별을 입력하지 않고 이용해 주세요.

구분내용
전송받는 자Google LLC (Gemini API)
전송 국가미국 등 해당 사업자가 서버를 운영하는 국가
전송 항목선택한 관심 분야, 뽑힌 카드 정보, 입력한 경우의 생년월일
전송 목적해석 문장 생성
전송 시점이용자가 해석을 요청하는 시점
보유 기간해당 사업자의 정책에 따름

성별은 전송하지 않습니다. 이름·연락처 등 이용자를 특정할 수 있는 정보는 전송 항목에 포함되지 않습니다.

4. 보유 기간 및 파기

  • 뽑기 결과와 해석 문장은 생성 후 1년이 지나면 자동 삭제합니다. 삭제된 결과의 공유 링크는 더 이상 열리지 않습니다.
  • 요청 이력(시각·응답 시간·모델명)은 생성 후 1년이 지나면 자동 삭제합니다.
  • 요청 제한을 위한 IP 기록은 1분 이내에 사라지며 별도로 저장하지 않습니다.

5. 이용자의 권리

회원 정보가 없어 이용자를 식별할 수 없으므로, 개별 결과의 열람·삭제 요청은 해당 결과의 공유 링크(주소)를 알려주시는 방법으로만 처리할 수 있습니다. 아래 연락처로 링크를 보내주시면 삭제해 드립니다.

6. 브라우저 저장소 이용

광고·분석용 쿠키를 사용하지 않습니다. 관심 분야와 선택 입력값을 뽑기 화면으로 넘기기 위해 브라우저의 세션 저장소(sessionStorage)를 잠시 사용하며, 이 값은 브라우저 탭을 닫으면 사라지고 서버로 따로 전송되지 않습니다.

8. 방침 변경

이 방침의 내용이 바뀌는 경우 변경 사항을 이 페이지에 게시합니다. 중요한 변경이 있을 때에는 시행일 기준 최소 7일 전에 안내합니다.

서비스의 해석 결과는 참고용 콘텐츠이며 의료·법률·투자 등 전문적 판단을 대체하지 않습니다.
